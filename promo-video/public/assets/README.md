# Asset Policy & Notice

## IMPORTANT: Official Logos & Insignia
In compliance with operational standards and security guidelines:
- Official Ministry of Interior (وزارة الداخلية), Egyptian Police (الشرطة المصرية), or Emergency Hotline 122 logos and insignia **must NOT** be committed or embedded in this repository without explicit, written authorization from the competent authorities.
- The project strictly uses a neutral, stylized placeholder emblem (simple geometric shield) for all UI layouts, composition previews, and development testing.
- Any production replacement of placeholder emblems with certified institutional assets must be handled via authorized deployment pipelines.
